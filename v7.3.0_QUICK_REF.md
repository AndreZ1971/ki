## 🔑 Authentication

### First-Time Setup
1. Navigate to `/login`
2. See "Setup Required" form
3. Enter password (8-16 chars, special chars required)
4. Submit → Logged in automatically

### Normal Login
1. Navigate to `/login`
2. Enter password
3. Submit → Authenticated

### Routes
- `POST /api/auth/check` - Check setup status
- `POST /api/auth/setup` - First-time setup
- `POST /api/auth/login` - Login
- `POST /api/auth/logout` - Logout
- `GET /api/auth/session` - Session status
- `POST /api/auth/change-password` - Change password

## 🔐 Specialization Signatures

### How it Works
```
WooCommerce (Private Key)
    ↓ Signs .ari-spec
Customer Downloads
    ↓ Uploads to Container
Container (Public Key)
    ↓ Verifies Signature
Valid? ✅ Accept | Invalid? ❌ 401
```

### File Structure
```json
{
  "format": "ari-specialization",
  "version": "1.0",
  "issuer": "kaufe-es.eu",
  "timestamp": 1770075228583,
  "signature": "dEwZu7uE99g7tq4YE3/qu...",  // RSA-4096
  "data": {
    "id": "beauty-kosmetik",
    "name": "Beauty Kosmetik",
    "systemPrompt": "...",
    "features": [...]
  }
}
```

## 🐛 Troubleshooting

### Upload Rejected (401)
**Cause**: Invalid or missing signature  
**Fix**: Use only signed .ari-spec files from kaufe-es.eu

### Can't Delete Specialization (409)
**Cause**: Specialization is active  
**Fix**: Activate a different spec first, then delete

### Login Failed
**Cause**: Wrong password or session expired  
**Fix**: Re-enter password, check connection.json exists
