## ⚡ Quick Start

### New Installation
```bash
# 1. Clone repo
git clone https://github.com/AndreZ1971/ki.git
cd ki

# 2. Install dependencies
npm install
cd backend && npm install
cd ../frontend && npm install

# 3. Build
npm run build

# 4. Start (production)
npm start
```

### Upgrade from v7.3.0
```bash
# 1. Pull changes
git pull origin master

# 2. Reinstall
npm install
cd backend && npm install
cd ../frontend && npm install

# 3. Rebuild
npm run build

# 4. Restart
docker-compose restart
```

## 🔐 Subscription Management

### Link-Based Approach
```
Customer clicks "Open Profile" button
        ↓
Navigates to https://kaufe-es.eu/index.php/mein-konto/wps_subscriptions/
        ↓
Views subscription details on profile page
        ↓
Manages renewal/cancellation directly in customer dashboard
```

### No Configuration Required
- ✅ No subscriptionId needed
- ✅ No wpSwingsSecret required
- ✅ No API integration
- ✅ Just a simple link

## 🐛 Troubleshooting

### Profile Link Not Working
**Cause**: Link configuration issue  
**Fix**: Verify URL is correct in SubscriptionTab.tsx

### Build Fails
**Cause**: Missing dependencies  
**Fix**: Run `npm install` in root, backend, and frontend

### Settings Page Errors
**Cause**: Old cached version  
**Fix**: Clear browser cache (Ctrl+Shift+Delete) and reload
