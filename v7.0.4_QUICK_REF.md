# 🚀 v7.0.4 Quick Reference Guide

**Version:** 7.0.4 | **Release:** 21. Januar 2026 | **Type:** Maintenance & Cleanup

---

## ⚡ Was ist neu in v7.0.4?

### 🔧 Hauptveränderungen
1. **Frontend API Standardisierung** - Alle hardcodierten `VITE_API_URL` entfernt
2. **Backend Product Types erweitert** - Jetzt 5 WooCommerce Produkttypen unterstützt
3. **MLDashboard Bug gefixt** - Infinite Loading Problem behoben
4. **Dokumentation aktualisiert** - Konsistente Versionierung überall

### 📊 Qualitätsmetriken
- ✅ **Build**: SUCCESS (12.843 Module)
- ✅ **Lint**: 0 Fehler, 0 Warnungen
- ✅ **Bundle**: 1.814 KiB (optimiert)

---

## 🎯 Wichtige Änderungen

### Für Entwickler
```typescript
// ALT (v7.0.3):
fetch(`${import.meta.env.VITE_API_URL}/api/products`)

// NEU (v7.0.4):
fetch('/api/products')  // Relative Pfade!
```

### Für DevOps
- ✅ Keine Umgebungsvariablen für API URL nötig
