# Support

## Before Asking for Help

Please check:

- README.md / README_EN.md
- docs/german/* and docs/english/*
- Existing issues and closed discussions

## Support Channels

- General project contact: info@ari-cloud.de
- Project website: https://ari-cloud.de
- Repository issues: use for reproducible bugs and feature requests

## What to Include

For technical support, include:

- Environment (OS, Node version, runtime mode)
- Relevant component (backend/frontend/tool/route)
- Exact error output and logs (sanitized)
- Steps to reproduce
- Expected vs actual behavior

## Security Issues

Do not disclose vulnerabilities publicly before mitigation.
Follow SECURITY.md for private reporting.

## License and Usage Questions

For legal/licensing questions, refer first to LICENSE.
If clarification is needed, include the specific LICENSE section in your request.
