# 🚀 v7.0.1 Quick Reference Guide

**Version:** 7.0.1 | **Release:** 20. Januar 2026 | **Type:** Critical Bugfix

---

## ⚡ Was ist neu in v7.0.1?

### 🔴 Kritischer Fix
- **Behoben:** Falsche Kundenbestellungszahlen in UserManagement
- **Ursache:** Veraltete WooCommerce `orders_count` Metadaten
- **Lösung:** Echtzeit-API-Abfragen mit paralleler Ausführung

### ✨ Neue Features
- 📋 **Bestelldetails im Modal** - Vollständige Bestellhistorie pro Kunde
- 🔄 **Neuer API-Endpoint** - `/customers/:id/orders` für detaillierte Bestellungen
- ⚡ **Performance-Optimierung** - Parallele Bestellungsabfragen

## 📋 Neue API-Endpoints

## 🐛 Fehlerbehebung

### Problem 1: Bestellungszahlen falsch
```bash
# 1. Backend-Logs prüfen
tail -f logs/app.log | grep "orders"

# 2. WooCommerce API testen
curl -u ck_xxx:cs_xxx https://shop.de/wp-json/wc/v3/orders?customer=123

# 3. Browser-Cache leeren
Ctrl+Shift+Del → "Cached Images and Files" → Clear
```

### Problem 2: "Anzeigen"-Button lädt nicht
```bash
# 1. DevTools öffnen (F12)
# 2. Network-Tab → Filter: "orders"
# 3. Auf Fehler prüfen (4xx, 5xx)

# 4. Backend-Endpoint manuell testen
curl http://localhost:3000/api/woocommerce/customers/123/orders
```

### Problem 3: Langsames Laden
```bash
# Normal bei vielen Bestellungen (100+)
# Workaround: Im Backend config.ts erhöhen
timeoutMs: 60000  // auf 60s erhöhen
```
