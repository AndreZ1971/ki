## 🎯 What's New

### ✨ A.R.I. Specialization Creator
A professional internal tool for creating `.ari-spec.json` files visually.

```bash
cd tools/spec-creator && npm run dev
# Access at http://localhost:5174
```

**Features at a Glance:**
- 4-step wizard (Basic Info → System Prompt → Features → Preview)
- Real-time validation with error messages
- System prompt templates
- Emoji picker for icons
- JSON preview & download
- Import/Export `.ari-spec` files
