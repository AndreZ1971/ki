## Architektur

### Frontend

**Framework:** react-i18next  
**Initialisierung:** `frontend/src/i18n.ts`  
**Locale-Dateien:**
- `frontend/src/locales/german.json` (603 Zeilen, 165+ Keys)
- `frontend/src/locales/english.json` (588 Zeilen, 165+ Keys)

**Verwendung in Komponenten:**
```tsx
import { useTranslation } from 'react-i18next';

function MyComponent() {
  const { t } = useTranslation();
  return <h1>{t('common.title')}</h1>;
}
```

**Key-Struktur:**
```json
{
  "common": {
    "back": "Zurück",
    "save": "Speichern",
    "cancel": "Abbrechen"
  },
  "settings": {
    "connection": {
      "title": "Verbindung",
      "saveButton": "Einstellungen speichern"
    }
  },
  "error": {
    "invalidFormat": "Ungültiges Format",
    "loadingFailed": "Laden fehlgeschlagen"
  }
}
```

### Backend

**Service:** `backend/services/i18nService.ts`

**Features:**
- Lädt Locale-Dateien vom Frontend
- Unterstützt verschachtelte Keys (Punkt-Notation)
- Erkennt Sprache aus Request-Headern
- Fallback zu Englisch bei fehlenden Keys
- Parameter-Interpolation

**Verwendung in API-Routen:**
```typescript
import { i18nService } from '../../../../services/i18nService';

// In Route-Handler
const locale = i18nService.getLocaleFromHeaders(request.headers);
const t = i18nService.createTranslator(locale);

return reply.status(400).send({
  success: false,
  error: t('error.noFileProvided')
});
```

**Request-Header:**
- `X-Language: de` → Deutsch
- `X-Language: en` → Englisch
- `Accept-Language: de-DE,de;q=0.9` → Deutsch
- Kein Header → Englisch (Standard)

## Key-Synchronisierung

### Keys prüfen
```bash
cd frontend
node -e "
const fs=require('fs');
const de=JSON.parse(fs.readFileSync('src/locales/german.json','utf8'));
const en=JSON.parse(fs.readFileSync('src/locales/english.json','utf8'));
const walk=(o,p='')=>Object.entries(o).flatMap(([k,v])=>
  v&&typeof v==='object'&&!Array.isArray(v)?walk(v,p?p+'.'+k:k):[p?p+'.'+k:k]
);
const deKeys=new Set(walk(de));
const enKeys=new Set(walk(en));
const missingInEn=[...deKeys].filter(k=>!enKeys.has(k));
const missingInDe=[...enKeys].filter(k=>!deKeys.has(k));
console.log('Fehlende Keys in EN:',missingInEn.length);
console.log('Fehlende Keys in DE:',missingInDe.length);
"
```

**Erwartetes Ergebnis:**
```
Fehlende Keys in EN: 0
Fehlende Keys in DE: 0
```

### Neue Keys hinzufügen

1. Key in `german.json` hinzufügen
2. Entsprechenden Key in `english.json` hinzufügen (gleiche Struktur)
3. Synchronisierung prüfen (siehe oben)

**Beispiel:**
```json
// german.json

    }
  }
}
```

## Übersetzungs-Guidelines

### Konsistenz
- ✅ Gleiche Begriffe immer gleich übersetzen
- ✅ Settings = "Einstellungen" (nicht "Konfiguration")
- ✅ Save = "Speichern" (nicht "Sichern")
- ✅ Dashboard = "Dashboard" (nicht übersetzen)

### Formatierung
- ✅ Keys in Kleinbuchstaben: `common.save`
- ✅ Verschachtelung nutzen: `settings.connection.title`
- ✅ Konsistente Namespace-Struktur
- ✅ Keine doppelten Keys

### Qualität
- ✅ Natürlich klingende Übersetzungen
- ✅ Kontextgerechte Formulierungen
- ✅ Professionelle Terminologie
- ✅ Keine maschinellen Übersetzungen ohne Review
