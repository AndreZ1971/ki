## Architecture

### Frontend

**Framework:** react-i18next  
**Initialization:** `frontend/src/i18n.ts`  
**Locale Files:**
- `frontend/src/locales/german.json` (603 lines, 165+ keys)
- `frontend/src/locales/english.json` (588 lines, 165+ keys)

**Usage in Components:**
```tsx
import { useTranslation } from 'react-i18next';

function MyComponent() {
  const { t } = useTranslation();
  return <h1>{t('common.title')}</h1>;
}
```

**Key Structure:**
```json
{
  "common": {
    "back": "Back",
    "save": "Save",
    "cancel": "Cancel"
  },
  "settings": {
    "connection": {
      "title": "Connection",
      "saveButton": "Save Settings"
    }
  },
  "error": {
    "invalidFormat": "Invalid format",
    "loadingFailed": "Loading failed"
  }
}
```

### Backend

**Service:** `backend/services/i18nService.ts`

**Features:**
- Loads locale files from frontend
- Supports nested keys (dot notation)
- Detects language from request headers
- Fallback to English for missing keys
- Parameter interpolation

**Usage in API Routes:**
```typescript
import { i18nService } from '../../../../services/i18nService';

// In route handler
const locale = i18nService.getLocaleFromHeaders(request.headers);
const t = i18nService.createTranslator(locale);

return reply.status(400).send({
  success: false,
  error: t('error.noFileProvided')
});
```

**Request Headers:**
- `X-Language: de` → German
- `X-Language: en` → English
- `Accept-Language: de-DE,de;q=0.9` → German
- No header → English (default)

## Key Synchronization

### Check Keys
```bash
cd frontend
node -e "
const fs=require('fs');
const de=JSON.parse(fs.readFileSync('src/locales/german.json','utf8'));
const en=JSON.parse(fs.readFileSync('src/locales/english.json','utf8'));
const walk=(o,p='')=>Object.entries(o).flatMap(([k,v])=>
  v&&typeof v==='object'&&!Array.isArray(v)?walk(v,p?p+'.'+k:k):[p?p+'.'+k:k]
);
const deKeys=new Set(walk(de));
const enKeys=new Set(walk(en));
const missingInEn=[...deKeys].filter(k=>!enKeys.has(k));
const missingInDe=[...enKeys].filter(k=>!deKeys.has(k));
console.log('Missing keys in EN:',missingInEn.length);
console.log('Missing keys in DE:',missingInDe.length);
"
```

**Expected Result:**
```
Missing keys in EN: 0
Missing keys in DE: 0
```

### Add New Keys

1. Add key to `german.json`
2. Add corresponding key to `english.json` (same structure)
3. Check synchronization (see above)

## Maintenance

### Add New Page

1. Create component with `useTranslation()`:
```tsx
import { useTranslation } from 'react-i18next';

export function NewPage() {
  const { t } = useTranslation();
  return <h1>{t('pages.newPage.title')}</h1>;
}
```

2. Add keys to both locale files:
```json
// german.json
{
  "pages": {
    "newPage": {
      "title": "Neue Seite",
      "description": "Beschreibung"
    }
  }
}

// english.json
{
  "pages": {
    "newPage": {
      "title": "New Page",
      "description": "Description"
    }
  }
}
```

3. Check synchronization

### Add Backend Route

1. Create route with i18nService:
```typescript
import { i18nService } from '../services/i18nService';

server.get('/api/my-route', async (request, reply) => {
  const locale = i18nService.getLocaleFromHeaders(request.headers);
  const t = i18nService.createTranslator(locale);
  
  return reply.send({
    message: t('myRoute.success')
  });
});
```

2. Add keys to locale files
3. Test with different `X-Language` headers

## Translation Guidelines

### Consistency
- ✅ Always translate same terms consistently
- ✅ Settings = "Einstellungen" (not "Konfiguration")
- ✅ Save = "Speichern" (not "Sichern")
- ✅ Dashboard = "Dashboard" (do not translate)

### Formatting
- ✅ Keys in lowercase: `common.save`
- ✅ Use nesting: `settings.connection.title`
- ✅ Consistent namespace structure
- ✅ No duplicate keys

### Quality
- ✅ Natural-sounding translations
- ✅ Context-appropriate wording
- ✅ Professional terminology
- ✅ No machine translations without review

## Known Limitations

- ⚠️ Dynamically generated text (e.g., from OpenAI) is not translated
- ⚠️ Log files remain in English
- ⚠️ API documentation only in English
- ⚠️ Commit messages only in English
