## 🚀 How to Use

### Switching Languages

1. **Look for the language flags** in the top-right corner of the dashboard
   - 🇩🇪 German
   - 🇬🇧 English

2. **Click the flag** to instantly switch to that language

3. **Your preference is saved** - When you return, the app will load in your chosen language

## ⚡ Quick Tips

### Troubleshooting

**Language not switching?**
- Try refreshing the page (F5 or Cmd+R)
- Clear browser cache
- Check if JavaScript is enabled

**Text not displaying correctly?**
- Ensure your browser supports UTF-8 encoding (all modern browsers do)
- Try a different browser
- Report the issue to support

**Language preference not saved?**
- Check if cookies/localStorage is enabled in your browser
- Try a different browser
- Clear browser cache and try again

### Browser Tips

**Chrome/Chromium:**
- Settings > Privacy & Security > Cookies and other site data > Allow all cookies

**Firefox:**
- Preferences > Privacy & Security > Cookies and Site Data > Allow

**Safari:**
- Preferences > Privacy > Cookies and website data > Allow from websites you visit
