## 🚀 Quick Start

### For Deployment
```bash
# Checkout the tag
git checkout v7.0.0

# Or pull to local
git fetch origin tag v7.0.0

# Verify tag signature
git tag -v v7.0.0

# View release notes
cat RELEASE_NOTES_v7.0.0.md

# View changelog
cat CHANGELOG.md
```

### For Docker
```bash
# Build from tag
docker build --tag ari:v7.0.0 .

# Run container
docker run -p 3000:3000 \
  -e WOOCOMMERCE_URL=https://yourdomain.com \
  -e CONSUMER_KEY=ck_... \
  -e CONSUMER_SECRET=cs_... \
  -e OPENAI_API_KEY=sk_... \
  ari:v7.0.0
```

## 🎯 For DevOps Teams

### Environment Setup
```bash
# Required Variables
export WOOCOMMERCE_URL=https://yourdomain.com
export CONSUMER_KEY=ck_xxxxxxxxxxxx
export CONSUMER_SECRET=cs_xxxxxxxxxxxx
export OPENAI_API_KEY=sk_xxxxxxxxxxxx

# Optional: Admin User
export ADMIN_USER=admin
export ADMIN_PASS=SecurePassword123

# Optional: Health Checks
export HEALTH_CHECK_TIMEOUT_MS=15000
```

### CI/CD Integration
```yaml
# .github/workflows/deploy.yml
- name: Deploy v7.0.0
  run: |
    git checkout v7.0.0
    npm install
    npm run build
    docker build -t ari:v7.0.0 .
    docker push registry/ari:v7.0.0
```

### Rollback (if needed)
```bash
# Revert to previous version
git checkout v6.9.0

# Or use specific commit
git checkout cd8d683

# Clear cache
npm run clean
npm install
npm run build
```
